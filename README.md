# DVD Rental Duration Prediction

Regression models predicting how many days a customer rents a DVD, to support
inventory planning. Includes feature engineering (rental length, dummy
variables for special features), Lasso-based feature selection, OLS, and a
Random Forest tuned with GridSearchCV. Target: test MSE ≤ 3.

**Tools:** Python, pandas, scikit-learn

*Guided project from [DataCamp](https://www.datacamp.com).*
